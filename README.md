# 🏆 AI Sports Rules Assistant

An AI-powered Sports Rules Assistant built using **Python**, **Streamlit**, and **Google Gemini AI**. This application helps users learn sports rules, understand sports terminology, search rule databases, and test their knowledge with interactive quizzes.

---

## 📌 Project Overview

The AI Sports Rules Assistant is an intelligent application designed to provide quick and accurate information about sports rules and terminology. It acts as a virtual assistant for students, sports enthusiasts, coaches, and beginners who want to learn different sports in an interactive way.

---

## 🚀 Features

### 🤖 AI Sports Assistant
- Ask sports-related questions in natural language.
- Powered by Google Gemini AI.
- Provides clear and accurate explanations.
- Ignores non-sports related questions.

---

### 📚 Sports Rules Database

Search and explore rules from multiple sports including:

- 🏏 Cricket
- ⚽ Football
- 🏀 Basketball
- 🎾 Tennis
- 🤼 Kabaddi

Each rule includes:
- Rule Name
- Description
- Easy-to-understand explanation

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/AI-Sports-Rules-Assistant.git
```

### Move into Project

```bash
cd AI-Sports-Rules-Assistant
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Create .env File

```
GEMINI_API_KEY=YOUR_API_KEY
```

### Run Application

```bash
streamlit run app.py
```
